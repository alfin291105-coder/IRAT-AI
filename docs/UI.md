# IRAT AI UI Guide

Panduan antarmuka (UI) untuk Project IRAT AI.

---

## Design Principles

* Simple
* Modern
* Minimalist
* Private-First
* Responsive
* Easy to use

---

## Chat Layout

* AI message on the left.
* User message on the right.
* Auto-scroll to the latest message.
* One continuous conversation.

---

## Navigation

* No "New Chat" feature.
* Settings page.
* Profile page.
* Chat page.

---

## Supported Platforms

* Android
* Windows
* iPhone

---

## Future UI Features

* Voice Chat
* Screen Sharing
* Dark Mode
* Light Mode
* Custom Wallpaper
* Theme Customization
