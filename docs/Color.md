# IRAT AI Color Guide

Standar warna antarmuka (UI) untuk Project IRAT AI.

---

## Background

| Element    | Color     |
| ---------- | --------- |
| Background | `#000000` |

---

## Chat Bubble

| Element     | Color     |
| ----------- | --------- |
| User Bubble | `#1EBEA5` |
| AI Bubble   | `#273443` |

---

## Border

| Element | Color     |
| ------- | --------- |

---

## Text

| Element      | Color     |
| ------------ | --------- |

## Design Principles

* Minimalist
* Private-first
* Dark theme by default
* High contrast for readability
* Consistent across Android, Windows, and iPhone
